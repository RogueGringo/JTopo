# driftwave has moved 👉 https://github.com/RogueGringo/driftwave

The `driftwave` plugin is no longer bundled in this monorepo. Its canonical,
maintained home is its own repository:

### https://github.com/RogueGringo/driftwave

The `jtopo-plugins` marketplace entry installs driftwave directly from there, so
`driftwave@jtopo-plugins` resolves to the current plugin. The old bundled copy
that used to live in this directory was a stale snapshot and has been removed;
see the canonical repo for all current code, history, and issues.
